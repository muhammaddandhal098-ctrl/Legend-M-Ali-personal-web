## ❓ Frequently Asked Questions (FAQs)

#### Q1: What is the purpose of this project?
> **Answer:** This application serves as a central personal workspace and public portfolio hub to demonstrate technical projects, manage daily productivity tools, and capture user feedback/messages.

#### Q2: Can I submit a voice message through the web app?
> **Answer:** Yes, click on "Start Recording" in the Voice Mail section, grant microphone access, record your message, and hit "Stop Recording" to review or submit.

#### Q3: How do background notifications work?
> **Answer:** Clicking "Enable Push Notifications" triggers the Web Notifications API. Once allowed, important updates or reminders are delivered directly to your device browser.

#### Q4: How are new projects added to the portfolio?
> **Answer:** New entries are submitted through the dynamic project form, which sends a `POST` request to the `/api/projects` serverless endpoint to update the live display.
